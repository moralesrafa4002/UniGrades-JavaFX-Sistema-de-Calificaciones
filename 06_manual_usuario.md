# Fase 0 — Resumen del proyecto

## Nombre del proyecto

**UniGrades JavaFX — Sistema de Administración y Consulta de Calificaciones Universitarias**

## Descripción

El sistema desarrollado es una aplicación de escritorio basada en JavaFX que permite administrar carreras, semestres, materias, usuarios, grupos, inscripciones y calificaciones dentro de un entorno universitario.

El proyecto considera tres roles principales: administrador, profesor y alumno. Cada rol tiene permisos y pantallas diferentes. Esta separación permite aplicar seguridad básica mediante autenticación y control de acceso por tipo de usuario.

## Problema que resuelve

En una universidad, el registro manual de calificaciones puede provocar errores, pérdida de información, cálculos incorrectos y falta de control sobre quién puede modificar datos. Este sistema propone una solución local donde los profesores pueden capturar calificaciones, los alumnos pueden consultarlas y el administrador puede mantener la estructura académica.

## Objetivo

Aplicar de forma integral Programación Orientada a Objetos, JavaFX, MVC, patrones de diseño, persistencia y validaciones en un sistema funcional de escritorio.

## Alcance

El sistema permite:

- Registrar carreras.
- Registrar materias por carrera y semestre.
- Registrar profesores y alumnos.
- Crear grupos.
- Inscribir alumnos.
- Configurar porcentajes de evaluación.
- Registrar calificaciones.
- Calcular promedio final automáticamente.
- Consultar estatus académico.
- Guardar información en archivos XML.
