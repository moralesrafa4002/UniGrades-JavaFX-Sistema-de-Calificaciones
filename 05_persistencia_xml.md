# Índice de documentación

Este proyecto está documentado por fases para que pueda revisarse como un trabajo académico completo.

1. `00_resumen_proyecto.md` — descripción general, objetivo y alcance.
2. `01_requerimientos_funcionales.md` — requerimientos por rol.
3. `02_modelo_datos.md` — entidades, relaciones y diccionario de datos.
4. `03_arquitectura_mvc.md` — explicación de la arquitectura por capas.
5. `04_patrones_diseno.md` — patrones Singleton, Strategy y Repository.
6. `05_persistencia_xml.md` — funcionamiento de la persistencia XML.
7. `06_manual_usuario.md` — guía de uso para administrador, profesor y alumno.
8. `07_defensa_individual.md` — preguntas y respuestas para explicar el proyecto.
9. `08_pruebas_validaciones.md` — casos de prueba y manejo de errores.
10. `09_referencias.md` — referencias utilizadas.
